# 🕷️ SpiderXz - WhatsApp Ban & Warning System

> *"dans l'ombre, je suis le meilleur."*

Un script d'automatisation pour WhatsApp (Node.js) conçu pour gérer les avertissements (`warn`) et les bannissements (`ban`) de manière radicale et stylisée. Ici, chaque erreur peut coûter la vie au compte de la cible.

## 🩸 Aperçu des Messages (WhatsApp Format)

### ⚠️ Statut : En Sursis (1/1 Vie)
```text
🩸 [avertissement fatal] 🩸
t'as cru que la cour de récré pardonnait ? ici on est des gosses, mais chaque erreur peut te coûter la vie. t'as de la chance, t'es pas encore off...
🖤 « mais t'inquiète pas, tôt ou tard spiderxz va te gérer. »
─ warning by spiderxz 🕷️
```

### ❌ Statut : Éliminé (0/1 Vie)
```text
🩸 [erreur fatale] 🩸
t'as cru que la cour de récré pardonnait ? ici on est des gosses mais chaque faux pas se paie cash. t'as joué, t'as fait l'erreur de trop.
🖤 « dans l'ombre, je suis le meilleur. »
─ off by spiderxz 🕷️
```

## 🚀 Fonctionnalités
- 📱 Connexion instantanée via **QR Code**.
- ⏳ Gestion de statut dynamique (**En sursis** / **Éliminé**).
- 💬 Formatage automatique avec les balises WhatsApp (`*bold*`, `_italic_`, `` `code` ``).

## 🛠️ Installation

```bash
# 1. Cloner le projet
git clone https://github.com

# 2. Entrer dans le dossier
cd SpiderXz-BanSystem

# 3. Installer les dépendances
npm install whatsapp-web.js qrcode-terminal
```

## ⚙️ Utilisation
Lancez le bot avec la commande suivante et scannez le QR code avec votre WhatsApp :
```bash
node bot.js
```
